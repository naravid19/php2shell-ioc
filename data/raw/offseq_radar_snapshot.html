Description

Two critical PHP remote code execution vulnerabilities will be patched in an emergency release on October 21. Fixes are only expected for supported PHP 8.x branches. Key takeaways CVE-2026-109618 and CVE-2026-109619 are critical vulnerabilities in PHP, both rated CVSSv4.0 9.2 by the PHP security team. Public reporting describes both as remote code execution vulnerabilities. watchTowr says it believes it has reproduced CVE-2026-109618, and Cloudflare CTO Dane Knecht says the company is seeing early attacks emerging. The patch release is scheduled for October 21, 2026 at 14:00 UTC. Version numbers reported before the release point to PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35. End-of-life branches are not expected to receive fixes. Impact

Successful exploitation of these vulnerabilities could allow unauthenticated attackers to execute arbitrary code on affected PHP servers, potentially leading to full system compromise. Given the critical severity and remote code execution capability, the impact is high. No confirmed in-the-wild exploitation has been reported yet, but the risk of rapid mass exploitation following patch release is significant.

Summary

The PHP2Shell vulnerabilities, CVE-2026-109618 and CVE-2026-109619, are critical remote code execution flaws in PHP that can be exploited without authentication. The vulnerabilities have a high CVSS score of 9.2 each. Although technical details are scarce, one is suspected to be a use-after-free bug. PHP versions 5 and later are reportedly affected. PHP has scheduled coordinated disclosure and patch release on October 21, 2026, and warns that patches may be expedited if exploitation occurs. Security firms confirm the vulnerabilities are real but have not seen active exploitation. However, mass exploitation is anticipated shortly after patches become available.
